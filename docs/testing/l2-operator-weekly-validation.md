# L2 Operator Weekly Validation

## Goal

Prove that one operator can run the Layer 2 desktop daily for five to seven working days and surface genuine procurement opportunities.

## Daily Checklist

1. Launch the desktop shell and confirm the runtime banner reflects the expected mode.
2. Trigger the day’s procurement ingestion run.
3. Review the contract queue for newly surfaced opportunities.
4. Open at least one process detail page and inspect notices, coverage, manifest, and errors.
5. Record at least one operator decision: approve, reject, or watch.
6. Review the errors page and clear or rerun any actionable failures.
7. Confirm daemon diagnostics remain readable from the daemon status page.

## End-of-Week Exit Criteria

- Daily ingestion completed on each working day.
- The queue surfaced genuine opportunities worth operator review.
- Approve / reject / watch decisions were captured without ghost state.
- Error handling and diagnostics were sufficient to keep work moving.
- The operator can explain whether the desktop MVP is valuable enough to justify the next layer.
