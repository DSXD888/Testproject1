## 3. CORE CONTRACTS / NON-NEGOTIABLES

1. **Hybrid two-stage:** Docling structural extraction → Claude semantic mapping. Always both stages.
2. **headless_contract mode** for all semantic skills. Not PTY. `interaction_profile: headless_contract` in SKILL.md frontmatter.
3. **Haiku tier** for semantic skills. `model_profile: structured_extract_low_cost`.
4. **Deterministic caching:** `(source_content_hash, extraction_engine_version, processing_strategy)` = cache key. Same inputs = skip re-extraction, clone authoritative row.
5. **Push-owned authority** for new tables. All sync tracking columns present. No SQL FKs from push-owned to local-only tables.
6. **No `unsafe` code.** `#![forbid(unsafe_code)]` is enforced.
7. **Rust 2024 edition.** Nightly toolchain required.
8. **No file deletion** without explicit owner permission (AGENTS.md Rule 1).
9. **Capability, not stage.** Extraction toolkit is invocable by any skill, not a fixed pipeline position.
10. **Single `target_domain` per semantic row.** Tender-specification → `"lots"`, pricing-schedule → `"pricing"`, bill-of-quantities → `"quantities"`, base → `"generic"`.
11. **Current-row supersession** in same transaction. `is_current = 0` + `superseded_by_*_id` before new row insert commits.
12. **Aggregate state** recomputed against `expected_overlays_json`, not naive row counts.
